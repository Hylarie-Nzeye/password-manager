# Password Manager - Flask App

This is a simple and secure **Password Manager** built using **Flask** (a Python web framework), **SQLAlchemy** (for database interactions), and **SQLite** (for local storage). The application allows users to securely manage their passwords for different websites, with features to add, update, delete, and export passwords.

## Features

- **Add Password**: Users can securely add email addresses, website URLs, and passwords.
- **Update Password**: Users can update existing password entries.
- **Delete Password**: Users can delete password entries.
- **Export Passwords**: Users can export all stored passwords to a CSV file for backup or sharing.
- **Responsive UI**: A simple and clean user interface that works well on both desktop and mobile devices.
- **Password Visibility Toggle**: Users can toggle the visibility of their passwords with a simple click of an icon.

## Technologies Used

- **Python**: The core programming language used to develop the backend of the application.
- **Flask**: Python web framework for building the web application.
- **SQLAlchemy**: Object-Relational Mapper (ORM) for interacting with the SQLite database.
- **SQLite**: A lightweight, serverless database used to store password data locally.
- **HTML/CSS**: Standard web technologies for creating the frontend of the application.
- **JavaScript**: Provides functionality to toggle password visibility.
