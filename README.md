# 🔐 Secure Password Manager – Flask & SQLAlchemy  

A secure password manager built with Flask, Python, and SQLAlchemy.  

## 🚀 Features  
- Secure user authentication with Flask-Login & JWT  
- Password encryption using bcrypt & Fernet  
- CRUD operations (Add, View, Update, Delete passwords)  
- Password generator for strong passwords  
- REST API with secure endpoints  
- Deployment ready (Render, Heroku, AWS)  

## 🛠️ Technologies Used  
- **Backend:** Flask (Python)  
- **Database:** SQLAlchemy (SQLite/PostgreSQL)  
- **Security:** Bcrypt, Flask-Login, Fernet Encryption
